# deevnet_bucket_key (Resource)

A further access key to one of your buckets, beside the `default` key every `deevnet_bucket` has. The key reaches its one bucket and nothing else. Needs API v0.23.0.

Give each thing that uses a bucket its own key, and give a reader a `read` key, so revoking one touches nothing else. Destroying the resource revokes the key.

**The API returns `secret_key` only when it creates the key**, so this state is the only copy you can read. Any change replaces the key, with a new secret. When the API no longer holds the key, the next plan replaces it. This resource cannot be imported: an import could never recover the secret.

## Example Usage

```terraform
# A read-only key for a workload that only serves the bucket's objects.
resource "deevnet_bucket_key" "media_reader" {
  tenant = deevnet_tenant.this.name
  bucket = deevnet_bucket.media.name
  name   = "reader"
  access = "read"
}

output "media_reader" {
  value = {
    access_key = deevnet_bucket_key.media_reader.access_key
    secret_key = deevnet_bucket_key.media_reader.secret_key
  }
  sensitive = true
}
```

## Schema

### Required

- `access` (String) `read` to list and get objects; `write` to list, get, put and delete objects and their versions.
- `bucket` (String) The bucket this key reaches: the `name` of a `deevnet_bucket`, not its `<tenant>-<name>` store name.
- `name` (String) The key's name, unique within the bucket: 1-20 characters, `a-z` first, then `a-z`, `0-9` and `-`. `default` is the bucket's own key.
- `tenant` (String) The tenant the bucket belongs to: the `name` of a `deevnet_tenant`.

### Read-Only

- `access_key` (String) The key's access key ID.
- `present` (Boolean) Whether the API still holds this key. When it does not, the next plan replaces it.
- `secret_key` (String, Sensitive) The key's secret access key. The API returns it only when it creates the key, so **this state is the only copy you can read**.
