# deevnet_secret (Resource)

One of your own runtime secrets, such as a key a third-party API gave you, written to your OpenBao namespace for your workloads to read (ADR-0021). The service is optional: a site that does not offer it answers with an error saying so. Needs API v0.22.0.

**The value never enters your plan or state.** `data_wo` is a write-only argument, which needs Terraform 1.11 or later. Feed it from a sensitive variable or `sensitive(...)`, and keep it encrypted in your own repository: that copy is the authoritative one, and OpenBao holds a runtime copy.

**A new value needs a new version.** Terraform cannot see a write-only value change, so changing `data_wo` alone does nothing. Raise `data_wo_version` with it, and the apply writes the new value.

**A lost secret is written again.** When OpenBao no longer holds the secret, as after a rebuild, the next plan shows it being created, and the apply writes it from your configuration. The same happens when the version OpenBao holds is not the one in your configuration.

A workload reads it through a `deevnet_secret_reader`. This resource cannot be imported: there is no way to import a value that is never read back.

## Example Usage

```terraform
# data_wo is write-only: it never enters your plan or state, and needs
# Terraform 1.11 or later. Keep the value encrypted in your own repository and
# pass it in, here as a sensitive variable.
variable "weather_api_key" {
  type      = string
  sensitive = true
}

resource "deevnet_secret" "weather" {
  tenant = deevnet_tenant.this.name
  path   = "weather/api"

  data_wo = {
    api_key = var.weather_api_key
  }

  # Terraform cannot see a write-only value change. Raise this with every new
  # value, and the apply writes it.
  data_wo_version = 1
}
```

## Schema

### Required

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `data_wo` (Map of String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The secret's value, as keys and string values, such as `{ api_key = var.weather_key }`. Write-only: it is sent when the secret is written and never stored in plan or state. Needs Terraform 1.11 or later. Changing it alone does nothing: raise `data_wo_version` with it.
- `data_wo_version` (Number) Your own counter for `data_wo`, from 1. Raising it writes the value again, which is how a new value reaches OpenBao.
- `path` (String) Where the secret lives in your namespace, such as `weather/api`: one to four segments joined by `/`, each 1-64 of `a-z`, `0-9`, `_` and `-`, and 128 characters at most.
- `tenant` (String) The tenant this secret belongs to: the `name` of a `deevnet_tenant`.

### Read-Only

- `id` (String) The secret's path.
