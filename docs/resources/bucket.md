# deevnet_bucket (Resource)

A bucket in your site's bucket store: S3-compatible object storage, reached at `endpoint` path-style (ADR-0026). Needs API v0.23.0, at a site that offers buckets; a site that does not answers with an error saying so.

**Creating a bucket also creates its `default` key**, with write access, in `access_key` and `secret_key`. The API returns the secret only when it creates the key, so **this state is the only copy you can read**. Use `deevnet_bucket_key` for further keys, such as a read-only one.

**The substrate stores your bucket's contents and does not back them up.** Keep your own copy of anything you cannot re-derive.

**The quota is enforced about a minute behind.** The store checks usage periodically, so writes can run past `quota_gb` briefly before they are refused. A single-part upload larger than the quota is refused at once, but a multipart upload, which is how most clients send a large object, is counted only after it completes, so one large object can take the bucket past its quota. Writes after it are then refused. The site has a fixed capacity, and quotas are allocated from it, never overcommitted: a create or a quota increase that would exceed it is refused with a message saying how much is left.

**`public_read` serves objects to the site network, never the internet:** anything on the site network that can reach the store can read them by name, without a key.

**Destroying a bucket that holds anything is refused** unless `force_destroy` is true, and that must be in state before the destroy: set it and apply first.

When the API no longer holds the bucket, the next plan replaces it, with a new `default` key. This resource cannot be imported: an import could never recover the key's secret.

## Example Usage

```terraform
resource "deevnet_bucket" "media" {
  tenant   = deevnet_tenant.this.name
  name     = "media"
  quota_gb = 10

  versioning = true

  # Not "lifecycle": Terraform reserves that name for its own meta-argument.
  object_lifecycle {
    noncurrent_expire_days = 30
  }

  # Set this and apply before a destroy that should empty the bucket.
  force_destroy = false
}

# The store does not back up the bucket. Keep your own copy of anything you
# cannot re-derive.
output "media_bucket" {
  value = {
    endpoint   = deevnet_bucket.media.endpoint
    bucket     = deevnet_bucket.media.bucket
    access_key = deevnet_bucket.media.access_key
    secret_key = deevnet_bucket.media.secret_key
  }
  sensitive = true
}
```

## Schema

### Required

- `name` (String) The bucket's name, unique within the tenant: 3-32 characters, `a-z` first, then `a-z`, `0-9` and `-`, ending in a letter or digit. The store's bucket is `<tenant>-<name>`, which must be 63 characters or fewer. Changing it replaces the bucket.
- `quota_gb` (Number) The bucket's quota, in GB, at least 1. Changes in place. Enforced about a minute behind; a multipart upload is counted only after it completes.
- `tenant` (String) The tenant this bucket belongs to: the `name` of a `deevnet_tenant`.

### Optional

- `force_destroy` (Boolean) Let a destroy delete everything in the bucket, every version included. Defaults to `false`, and then a destroy of a bucket that holds anything is refused. Kept by the provider, not the API: it takes effect from state, so apply it before the destroy.
- `object_lifecycle` (Block, Optional) When the store expires objects by itself. Omit it, or a value in it, for none. (see [below for nested schema](#nestedblock--object_lifecycle))
- `public_read` (Boolean) Serve the bucket's objects without a key, by name: anonymous `GetObject` and nothing else, so not a listing. Defaults to `false`. **Public here means the site network:** anything on it that can reach the store can read the objects. The store is never reachable from the internet.
- `versioning` (Boolean) Keep every version of each object. Defaults to `false`. Setting it back to `false` suspends versioning: the versions already kept stay, because S3 cannot un-version a bucket.

### Read-Only

- `access_key` (String) The `default` key's access key ID.
- `bucket` (String) The store's name for the bucket, `<tenant>-<name>`: what an S3 client calls it.
- `endpoint` (String) The bucket store's S3 endpoint, such as `https://s3.mobile.deevnet.net`. Use path-style addressing.
- `present` (Boolean) Whether the API still holds this bucket. When it does not, the next plan replaces it.
- `secret_key` (String, Sensitive) The `default` key's secret access key. The API returns it only when it creates the key, so **this state is the only copy you can read**.
- `status` (String) `ready` once the bucket is in the store; `provisioning` or `deleting` while the API is working on it.

### Nested Schema for `object_lifecycle`

Optional:

- `expire_days` (Number) Expire each current object this many days after it was written, at least 1. In a versioned bucket, the object becomes a noncurrent version.
- `noncurrent_expire_days` (Number) Delete each noncurrent version this many days after it stopped being current, at least 1.
