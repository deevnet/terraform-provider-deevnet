# deevnet_secret_reader (Resource)

A credential one of your workloads reads its secrets with: an AppRole in your OpenBao namespace that may read the `deevnet_secret` paths you list, and nothing else (ADR-0021). Needs API v0.22.0.

**Push `role_id` and `secret_id` with your code** (ADR-0034), and run OpenBao Agent on the workload with AppRole auto-auth against `addr`, in `namespace`. The agent logs in, renders your secrets where your service reads them, and renews its own token.

**The credential works only from the workload's own address.** A copy taken anywhere else cannot log in.

**Any change issues a new `secret_id`** and revokes the old one, so push again after an apply that changes this resource. When OpenBao no longer holds the reader, as after a rebuild, the next plan shows it being created, and the apply issues a new credential to push.

## Example Usage

```terraform
# The credential the lightd workload reads its secrets with. It works only
# from that workload's own address.
resource "deevnet_secret_reader" "lightd" {
  tenant   = deevnet_tenant.this.name
  name     = "lightd"
  workload = deevnet_workload.lightd.name
  paths    = [deevnet_secret.weather.path]
}

# Push these with your code, and point OpenBao Agent's AppRole auto-auth at
# them: role_id and secret_id as the method's files, addr as vault.address,
# and namespace as the namespace. Any change to the reader issues a new
# secret_id, so push again after it.
output "lightd_bao" {
  value = {
    addr      = deevnet_secret_reader.lightd.addr
    namespace = deevnet_secret_reader.lightd.namespace
    role_id   = deevnet_secret_reader.lightd.role_id
  }
}

output "lightd_bao_secret_id" {
  value     = deevnet_secret_reader.lightd.secret_id
  sensitive = true
}
```

## Schema

### Required

- `name` (String) The reader's name: 1-32 of `a-z`, `0-9` and `-`.
- `paths` (List of String) The secret paths it may read: the `path` of each `deevnet_secret`, 1 to 32 of them.
- `tenant` (String) The tenant this reader belongs to: the `name` of a `deevnet_tenant`.
- `workload` (String) The workload that reads with it: the `name` of a `deevnet_workload`. The credential works only from that workload's address.

### Read-Only

- `addr` (String) OpenBao's address, for the agent's `vault.address`.
- `namespace` (String) Your OpenBao namespace, where the agent logs in and reads.
- `role_id` (String) The AppRole's role ID, which the agent logs in with beside `secret_id`.
- `secret_id` (String, Sensitive) The AppRole's secret ID. A new one is issued on every change to this resource, and the old one stops working.
